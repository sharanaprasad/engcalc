EngCalc is a calculator built for engineers: 2.2k, 10p and 5MHz just work, complex numbers and matrices are built in, and it can even differentiate, integrate and take Laplace transforms. It runs entirely in your browser — nothing you type leaves your device.

Your first minute

        
There is one input line at the bottom. Type, press Enter, read the answer. That is the whole idea.

        

        

        

        
Answers come back in engineering notation (4.7k, 25n) with the plain number underneath. Everything is clickable:

        
    
          
  • Click a result to copy it.
    • 
          
  • Click an old input to put it back on the input line.
    • 
          
  • ↑ ↓ walk through what you typed before. Tab completes a function name.
    • 
          
  • ans is the previous result (ans2 the one before).
    • 
          
  • The line above the input shows a live preview while you type.
    • 
        

        
Stuck? Type help for the compact reference, or press F1 any time to come back to this guide.

Engineering notation

        
Glue a one-letter multiplier straight onto a number. Units after it are simply ignored, so you can write them the way you would on paper.

Case matters. 5m is milli (0.005) but 5M is mega (5,000,000). Units such as F, Hz, V, Ω after the number are fine: 10pF, 2.2kΩ.

        
The header buttons ENG / SCI / FIX change how results are shown, and − 6 + sets the number of significant digits (or type mode sci, digits 8).

Convert & reformat

        
Add to (or in) and a target at the end of any line to show the result differently. The stored value never changes.

        

        

        

        

        

        
Targets: a suffix letter (k, M, n…), eng sci fix, number bases hex bin oct dec, and angles deg rad. For bit-level work open the .

      


      

        
4

        
Variables & your own functions

        
Use = to store a value. Stored names appear in the Variables panel on the left; click one to drop it into your input.

        

        
Define a function with parentheses on the left. Always write multiplication with *: 2*x, 3*(4+1), 2*pi. Typing 2x gives a message telling you to add the *.

        

        
Name rules. The multiplier letters a f p n u m k M G T P can’t be names, because 2p must always mean pico. Use names like R1, C_load, x1. Names can’t start with a digit.

        
Tidy up with del x (one name), delall (all variables) or clear (the screen and all variables).

      


      

        
5

        
Complex numbers & angles

        
Use j for the imaginary unit. Magnitude, phase, polar form and the usual arithmetic are built in.

        

        

        

        

        
Angles are always radians, like most tools. When you want degrees, convert the result with in deg, or use sind, cosd, tand. To feed degrees in, write sin(30 in rad).

Solving equations

        
Any = that isn’t a plain assignment is treated as an equation to solve. Solutions are stored as variables so you can keep using them.

        
Equation or assignment? A plain name on the left is always an assignment: x = 5, x = y. Anything else on the left makes an equation: 2*x = 4, cos(x) = x. To solve something like x = y, start the line with eq: — then every part of the line is an equation. eq x,y: … also says which names are the unknowns.

        

        

        

        

        
Linear systems of any size work, including complex coefficients; single quadratics use the quadratic formula (complex roots too).

        
Polynomials of any degree give every root, real and complex. roots(...) does the same for an expression, or for a row of coefficients (highest power first):

        

        

        
Any other equation is solved numerically: every real root between -10 and 10 is listed. Give a range with solve(equation, x, a, b); if there are roots outside the default range, a note says so.

        

        

        
Nonlinear systems use Newton’s method from many starting points and list each distinct solution (x1, y1, x2, y2, …):

        

        

        
The  gives you a bigger box for larger systems.

Matrices

        
Write rows separated by ; and columns separated by spaces (or commas). The word matrix is optional.

        

        

        
Solve A·x = b with inv(A)*b:

        

        
You also have A' (transpose), A^2, A^-1, A(2,1) (one entry), trace, rank, eye(n), zeros(r,c), ones(r,c). Glue a minus to its number to start a new entry: [1 -2] has two entries, [1 - 2] has one.

Calculus & algebra

        
diff and integ work on formulas, not just numbers, and the answers come back as expressions you can copy and reuse. In the console they are typeset like a textbook (fractions, powers, roots); clicking one copies it as text you can type back in, and the TeX button copies LaTeX. pretty off shows plain text instead.

        

        

        

        

        
    
          
  • With one variable you can leave it out: diff(x^3). With several, name it: diff(R1*x^2, x).
    • 
          
  • integ(f) gives an antiderivative + C. Add limits for a number: integ(f, x, a, b), using inf for infinity.
    • 
          
  • When there is no closed form, a definite integral falls back to accurate numeric integration and says so.
    • 
          
  • diff(f, x, 2) is the second derivative.
    • 
        

        

        
Limits, series and sums. Exact constants such as π, e and √2 are recognised in the answers.

        

        

        

        

        

        
    
          
  • limit(f, x, a); a can be inf. Add left or right for a one-sided limit: limit(1/x, x, 0, right). If the two sides differ or the expression oscillates, it says so.
    • 
          
  • series(f, x, a, n) is the Taylor series about a up to power n (defaults 0 and 5).
    • 
          
  • sum(f, k, a, b): b can be a number, inf, or a name such as n for a closed form (polynomial and geometric terms).
    • 
        

        
Algebra.

        

        

        

        
    
          
  • factor also cancels fractions (factor((x^2-1)/(x^2+3*x+2))), takes out common factors (factor(x^2*y + x*y^2)) and splits whole numbers into primes (factor(360)).
    • 
          
  • simplify tries expanding, factoring, cancelling and identities, and keeps the shortest result that still gives the same values.
    •

Laplace & differential equations

        
LT transforms a time function into s; ILT goes back. poles and zeros read off the roots and store them as p1, p2… and z1, z2… Use u(t) for the unit step and delta(t) for the impulse.

        

        

        

        
Name a transfer function with parentheses and get its step response by dividing by s:

        

        
Repeated and complex poles, delays like exp(-s*T), and impulse terms are all handled. Write 2*u(t) rather than 2u(t), because 2u means 2 micro.

        
Differential equations. dsolve solves a linear equation with constant coefficients the way you would by hand: Laplace transform, solve for Y(s), transform back. Write y' for dy/dt and y'' for d²y/dt², then the initial conditions:

        

        

        

        
    
          
  • Any name works for the unknown function (v, i, x…) and for time (t by default). Initial conditions you leave out are 0, and the answer says so.
    • 
          
  • The input on the right can be anything LT handles: steps u(t-T), impulses delta(t), exp, sin, cos, powers of t.
    • 
          
  • The answer is stored as a function, so y(2) evaluates it and plot(y(t), t, 0, 10) draws it.
    •

Plots & Bode

        
Plot any function of one variable, with the variable name you choose. A preview appears right in the console, and the Plot tab lets you add markers and labels and export the result for a slide.

        

        

        
    
          
  • plot(expr, var, a, b): up to three expressions, then the variable name, then the range. The range accepts 1k, 10M… Add logx, logy, loglog or stacked at the end.
    • 
          
  • Wrap a trace in right(…) to give it its own right-hand y axis, e.g. a voltage and a current on one picture.
    • 
          
  • Any variable works: t for time, f for frequency, w for rad/s. Defined values like R1 count as constants.
    • 
        

        
Bode plots: give a transfer function in s and a frequency range. Magnitude (dB) is stacked over phase (°) on a log axis. Frequencies are rad/s; add hz to use Hz.

        

        

        

        
Markers are yours to place. In the  open Markers and either press 📍 at cursor after pointing at the curve (or tapping it on a phone), type an x value, or type a y level such as -3 to drop a marker wherever the trace crosses it. Edit the label text (\n makes a new line) or remove any marker.

        
3D plots: a surface z = f(x, y) or a space curve. Open it in the Plot tab to turn it with your finger or mouse (or the sliders), zoom, and export a PNG for slides.

        

        

        

        
Surface styles: add wire for a wireframe, or contour / heat for the top-down colour map, where moving the pointer over the map reads x, y and z. Without names, plot3d(f, a, b, c, d) uses the unknown names in alphabetical order (x before y). Colour always goes from light (low) to dark (high); the bar on the right shows the values.

        
When it looks right, open Export for slides: choose Light or Dark and a size, then Copy image for PowerPoint, Download PNG, or CSV data. Each plot has its own axis names and units under Axes & labels.

Tabs & panels

        

          
Console
Where everything above happens. History scrolls up; each answer is clickable.

          
Solver
A multi-line box for bigger linear systems, with examples and the coefficient matrix shown.

          
Base converter
Type in decimal, hex, binary, octal or any base; click individual bits; see two’s complement.

          
Plot
Plots with log axes, two y axes, stacked Bode panels, markers you place yourself, and PNG / CSV export.

          
Formulas
A series explorer (watch sin x build up term by term, with the error) plus reference tables: integrals, identities, Laplace pairs, small-x approximations and RF/analog formulas.

          
LaTeX
Type calculator syntax, copy LaTeX for reports and PowerPoint, with a live preview. Several lines become an aligned block.

          
⚛ Constants
Boltzmann, Planck, electron charge, speed of light and more. Click one to insert it.

          
ƒ Functions
Every built-in function, grouped, with a search box (Ctrl+K). Hover for the signature and an example.

Good to know

        

          
Why did 5m and 5M give different answers?
Multiplier letters are case-sensitive: m = milli, M = mega. This follows SI, so 5mV and 5MV mean what you expect.

          
Why is sin(90) not 1?
Angles are radians. Use sind(90), or sin(90 in rad) to convert from degrees first.

          
Why is 2x an error?
Multiplication is always written with *, so there is never any doubt about what you meant: write 2*x, 3*s, 2*pi, 2*(x+1). A letter glued to a number is only allowed when it is a multiplier or unit: 2.2k, 10pF, 5ms, 4j. Names must start with a letter (x1, R_load).

          
My result looks like a formula, not a number.
Results of diff, integ and LT are symbolic. Give the variable a value (x = 2) and use the result in arithmetic to get a number.

          
What does clear clear?
The screen and every stored variable, function and ans. Use del x or delall to remove variables without clearing the screen.

          
Is my work saved?
Variables, functions and your settings are kept in this browser, on this device only. Nothing is sent anywhere.

          
Why “Unknown name”?
You used a name that isn’t defined. Define it with name = value, or check the spelling. Function names need brackets: sin(x).
